# Wall Street Weather terminal

Run from the repository root:

```bash
npm run prototype
```

Then open `http://localhost:4173`.

The dashboard is a fixed, no-page-scroll financial terminal. Four company tabs sit across the top. A single left control rail contains the active company’s three metrics, submitted quote, and engine contribution toggles; the prediction/actual chart fills all remaining space. Long histories scroll horizontally inside the chart without scrolling the page. Reasoning appears only in the cinematic trace instead of permanently consuming a second side rail.

`dashboard/data/five-year-backtest.json` is generated by the audited replay in `forecast/historical_backtest.py`. It contains 20 requested fiscal periods for each of four companies: 80 company-periods, 240 metric slots, and 195 filing-sourced actuals. Home Depot, Analog Devices, and Deere have full coverage. Hays remains sparse because the challenge metrics are annual; the UI shows unavailable quarters instead of inventing data.

The central chart displays every validated period supplied by the selected method, rather than truncating to a five-year window. Long series begin at their first observation and use a tightly fitted horizontal scroller. The prediction path is divided into four chronological strike segments. **Run trace** opens a reasoning popup without zooming or hiding the dashboard. Each explicit click draws one lightning segment and reveals the next reasoning state; the final click resolves the electricity into the exact path and exposes **Replay**.

The three rows in **Contributions** are interactive controls. Active Street, Fundamental, and Prediction Market estimates appear as labelled nodes beside the submission marker and converge into the lightning endpoint. Turning an available engine off removes its node and connector, renormalises the remaining blend, and moves the final number and lightning trajectory. An unavailable prediction-market mapping remains visibly abstained and cannot be enabled; the interface does not fabricate a signal.

The compact Anchor / Driver / ML / Market selector above the chart comes from Uri's forecast explorer. It switches the historical prediction line to the chosen method's complete walk-forward series while keeping reported actuals fixed. Every method remains selectable: where a method has no dedicated backtest, the graph explicitly falls back to the meta replay while **Details** still exposes its summary, all three outputs, rationale, validation gate, derivation, and dated sources. The contribution dots and final number come from `submission/forecast-audit.json`, so method research and submitted meta-weights remain distinct and auditable.

The localized moving cloud uses the Mixkit clip recorded in `THIRD_PARTY_NOTICES.md`. Trace events remain illustrative until the backend implements the ordered `TraceEvent` contract in `AGENTS.md`.
