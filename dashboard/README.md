# Wall Street Weather terminal

Run from the repository root:

```bash
npm run prototype
```

Then open `http://localhost:4173`.

The dashboard is a fixed, no-page-scroll financial terminal. Four company tabs sit across the top, followed by the active company’s three metrics, submitted quote, and three source contributions. The prediction/actual chart fills the remaining space. Long histories scroll horizontally inside the chart without scrolling the page. Reasoning appears only in the full-canvas Details view instead of permanently consuming a side rail.

`dashboard/data/five-year-backtest.json` is generated by the audited replay in `forecast/historical_backtest.py`. It contains 20 requested fiscal periods for each of four companies: 80 company-periods, 240 metric slots, and 195 filing-sourced actuals. Home Depot, Analog Devices, and Deere have full coverage. Hays remains sparse because the challenge metrics are annual; the UI shows unavailable quarters instead of inventing data.

The central chart displays every validated period supplied by the selected method, rather than truncating to a five-year window. Long series begin at their first observation and use a tightly fitted horizontal scroller. Reported actuals use a solid dark line; predictions use a dashed blue lightning line with hollow markers; validation errors are green inside the declared gate and red outside it.

The compact Ensemble / Prediction Market / Expert / Aggregate Final selector above the chart switches the historical prediction line to the chosen method's exact walk-forward series while keeping reported actuals fixed. Ensemble is always the default; legacy `anchor`, `driver`, and `ml` method links resolve to Ensemble. Prediction Market renders its native 0–100% probability history where an exact market exists. If a selected source has no exact per-period series for the metric, the dashboard says so rather than borrowing another method's graph. Aggregate Final alone uses the audited 20-period meta-forecast replay.

**Details** is the single reasoning entry point. It replaces the complete chart canvas with five source-specific pages — Overview, Evidence, Derivation, Validation, and Output — while leaving the compact forecast strip visible. Back and Next move between pages; Finish, the close control, and Escape all return to the chart. Street, Fundamental, and Prediction Market contributions remain independently toggleable above the chart; changing a contribution switches to Aggregate Final and visibly moves the submitted endpoint.

The localized moving cloud uses the Mixkit clip recorded in `THIRD_PARTY_NOTICES.md`. Trace events remain illustrative until the backend implements the ordered `TraceEvent` contract in `AGENTS.md`.
