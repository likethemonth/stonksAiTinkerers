# Wall Street Weather terminal

Run from the repository root:

```bash
npm run prototype
```

Then open `http://localhost:4173`.

The dashboard is a fixed, no-page-scroll financial terminal. Four company tabs sit across the top, followed by the active company’s three metrics, submitted quote, and three source contributions. The prediction/actual chart fills the remaining space. Long histories scroll horizontally inside the chart without scrolling the page. Reasoning appears only in the cinematic trace instead of permanently consuming a side rail.

`dashboard/data/five-year-backtest.json` is generated by the audited replay in `forecast/historical_backtest.py`. It contains 20 requested fiscal periods for each of four companies: 80 company-periods, 240 metric slots, and 195 filing-sourced actuals. Home Depot, Analog Devices, and Deere have full coverage. Hays remains sparse because the challenge metrics are annual; the UI shows unavailable quarters instead of inventing data.

The central chart displays every validated period supplied by the selected method, rather than truncating to a five-year window. Long series begin at their first observation and use a tightly fitted horizontal scroller. Reported actuals use a solid dark line; predictions use a dashed blue line with hollow markers; validation errors are green inside the declared gate and red outside it. The prediction path is divided into four chronological strike segments. **Run trace** opens a reasoning popup without zooming or hiding the dashboard. Each explicit click draws one lightning segment and leaves that segment illuminated while revealing the next reasoning state. **Finish** immediately removes the reasoning popup, resolves the electricity into the exact path, and exposes **Replay**.

The compact Ensemble / Prediction Market / Expert / Aggregate Final selector above the chart switches the historical prediction line to the chosen method's complete walk-forward series while keeping reported actuals fixed. Ensemble is always the default; legacy `anchor`, `driver`, and `ml` method links resolve to Ensemble. Prediction Market renders its native 0–100% probability history where an exact market exists; otherwise the graph explicitly falls back to the meta replay instead of disabling the control. Expert uses the existing blinded expert-nowcaster replay, while Aggregate Final uses the audited meta-forecast replay. **Details** exposes each method's summary, outputs, rationale, validation gate, derivation, and dated sources. Street, Fundamental, and Prediction Market contributions remain independently toggleable above the chart; their graph nodes, weights, and final number come from `submission/forecast-audit.json`, so method research and submitted meta-weights remain distinct and auditable.

The localized moving cloud uses the Mixkit clip recorded in `THIRD_PARTY_NOTICES.md`. Trace events remain illustrative until the backend implements the ordered `TraceEvent` contract in `AGENTS.md`.
